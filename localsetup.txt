ANKIT PORTFOLIO — LOCAL SETUP
=============================

REQUIREMENTS
------------
- Node.js 18 LTS (react-scripts 5.0.0 / CRA is unmaintained and breaks on
  newer Node majors, e.g. Node 20+/24 fail to compile with
  "Module.createRequire is not a function"). Use nvm to manage this.
- npm (comes with Node)

ONE-TIME SETUP
---------------
1. Install nvm (if not already installed):
   curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

2. Install and switch to Node 18:
   export NVM_DIR="$HOME/.nvm"; [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
   nvm install 18
   nvm use 18

3. Install dependencies. This project has one outdated peer dependency
   (react-typical only declares support for React 15/16, project uses
   React 17), so npm's strict resolver needs --legacy-peer-deps:
   npm install --legacy-peer-deps

EVERY TIME (new terminal session)
-----------------------------------
export NVM_DIR="$HOME/.nvm"; [ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
nvm use 18

RUN THE DEV SERVER
-------------------
npm start
Opens at http://localhost:3000 (hot reload on file changes).

PRODUCTION BUILD
------------------
CI=true npx react-scripts build
Output goes to ./build. "CI=true" makes warnings not fail the build.

DEPLOY (GitHub Pages, per package.json)
------------------------------------------
npm run deploy
(runs predeploy -> build, then gh-pages -d build, publishing to the
"homepage" URL in package.json)

NOTES
-----
- Tailwind CSS is loaded via CDN script tag in public/index.html
  (no local Tailwind build step / tailwind.config.js file). Custom
  fonts (Inter, Sora) and the fontFamily theme extension are also
  configured inline there.
- node_modules is not committed; always run npm install after a fresh
  clone or after switching Node versions.
- If you ever see "Module.createRequire is not a function" again,
  it means something is running under a Node version other than 18 —
  re-run `nvm use 18` and retry.
